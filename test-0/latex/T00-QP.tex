\section*{Block B --- Working \hfill \normalfont\small(3 items, about 8 minutes)}
\textbf{Show your working.} There is more than one valid route through each of these; I am interested
in the route you take.

\begin{enumerate}[label=B\arabic*.,leftmargin=*]
  \item A factory has two machines. The first makes 60\% of the items and 2\% of what it makes is
    defective. The second makes the rest, and 5\% of what it makes is defective. An item is picked at
    random and found to be defective. How likely is it that the first machine made it?

    \vspace{45mm}

  \item For a fixed set of numbers $y_1, \dots, y_n$, find the value of $c$ that makes
    $\;S(c) = \sum_{i=1}^{n} (y_i - c)^2\;$ as small as possible. State how you know your answer is a
    minimum and not a maximum.

    \vspace{45mm}

  \item Consider the following function.
\begin{lstlisting}
def summarise(values):
    total = 0
    for v in values:
        total = total + v
    return total / len(values)
\end{lstlisting}
    What does \texttt{summarise([2, 4, 6])} return? What does \texttt{summarise([])} do?
    Explain how you worked each one out.

    \vspace{35mm}
\end{enumerate}

\section*{Block D --- Debug \hfill \normalfont\small(1 item, about 6 minutes)}
\begin{enumerate}[label=D\arabic*.,leftmargin=*]
  \item The function below is meant to train and evaluate a model honestly. There is exactly one
    fault in it.
\begin{lstlisting}
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier

def evaluate(X, y):
    scaler = StandardScaler()
    X_scaled = scaler.fit_transform(X)

    X_train, X_test, y_train, y_test = train_test_split(
        X_scaled, y, test_size=0.25, random_state=0)

    model = KNeighborsClassifier(n_neighbors=5)
    model.fit(X_train, y_train)
    return model.score(X_test, y_test)
\end{lstlisting}
    Answer three things: \textbf{(i)} what is wrong, \textbf{(ii)} why it matters, and
    \textbf{(iii)} how you would confirm that this is really the problem.

    \vspace{60mm}
\end{enumerate}
