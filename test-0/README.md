## What it was, and what it was not

The paper says so itself, and it is worth repeating now that you have the answers: **Test-0 sorted
nobody.** It did not group you, it did not decide which set of any later quiz you were handed — those
are allocated at random — and nothing on your script affects your marks. It exists so that the
teaching can respond to what the cohort actually finds hard.

## Using the solutions

There is no score to check against, so the useful comparison is a different one: how far your answer
was from a complete one, and which of the six blocks you want to shore up before the material that
depends on it arrives.

Roughly where each block lands later in the course:

| Block | What it was testing | Where it returns |
|---|---|---|
| A — Warm-up | Prerequisite recall | Throughout |
| B1 — Probability | Conditional probability, stated in words | Unit VI, Bayesian algorithms (L15) |
| B2 — Minimising a squared error | Differentiate, or complete the square | Unit V, least squares (L8) |
| B3 — Reading Python by hand | Tracing a loop; the empty-input case | Every lab |
| C — Explaining overfitting | Train/test gap, and how you explain it | Unit I (L1), Unit V (L9), Unit VI (L19) |
| D — Debug | Scaling fitted before the split: leakage | Unit IV, L5 and L7 |
| E — Getting started | Asking what is missing before choosing a method | Unit IV (L5, L7); the project |
| F — Estimation | Order-of-magnitude reasoning, stated assumptions | Every lab that loads an image set |

Several questions have more than one good route to the answer, and a route different from the printed
one is not automatically worse. If you reached a different answer and can show your reasoning, bring
your script.
