\section*{Objective}

\begin{itemize}[leftmargin=*]

  \item Build a scoring model where the two error types have very different costs.

  \item Use ROC and AUC correctly, and know what they hide.

  \item Examine a model for disparate outcomes across groups.

\end{itemize}

\section*{Datasets used in this assignment}

\textbf{A3 (Statlog German Credit).}\\ Full descriptions, sources and loading snippets for all anchor datasets are in \texttt{Anchor-Datasets.pdf}, alongside this brief.

\section*{Instructions}

\begin{itemize}[leftmargin=*]

  \item Use a train/test split (80/20 unless stated) and set \texttt{random\_state} for reproducibility.

  \item Fit every transformer inside a \texttt{Pipeline} so nothing is fitted on the test set.

  \item Report the metric named in the question. A number without units or context earns no marks.

  \item Every question asks for a short written observation. Code without commentary caps you at half marks.

  \item The lab quiz that follows will ask you to read, trace and modify \emph{your own} submitted code.

\end{itemize}

\textbf{Submit:}

\begin{itemize}[leftmargin=*]

  \item Notebook: \texttt{AML\_LA07\_<SAPID>.ipynb} with all cells executed and outputs visible.

  \item Report: 2--3 pages PDF, or a \texttt{README.md}, carrying your results table and observations.

  \item Do not upload datasets. Cite the source and include the loading code.

\end{itemize}

\section*{Section A (Easy) --- attempt any 2 of 3 \quad (2 $\times$ 2 = 4)}

\begin{enumerate}[label=\textbf{A\arabic*.}, leftmargin=*]

  \item \textbf{Load and baseline} \QMarks{2}\\
    \emph{Dataset: A3 (credit-g). Target: \texttt{class}.}
    \begin{enumerate}[label=(\alph*), leftmargin=*]
      \item Fetch the dataset, report its shape and the proportion of bad-credit cases.
      \item Fit a logistic regression in a pipeline with one-hot encoding and scaling; report accuracy.
      \item State the majority-class accuracy and compare in two lines.
    \end{enumerate}

  \item \textbf{The cost matrix} \QMarks{2}\\
    \emph{Dataset: A3.}
    \begin{enumerate}[label=(\alph*), leftmargin=*]
      \item Print the confusion matrix for your A1 model.
      \item The dataset's own documentation says lending to a bad customer costs five times as much as refusing a good one. Compute your model's total cost under that matrix.
      \item State in two lines whether accuracy was the right metric.
    \end{enumerate}

  \item \textbf{ROC and AUC} \QMarks{2}\\
    \emph{Dataset: A3.}
    \begin{enumerate}[label=(\alph*), leftmargin=*]
      \item Plot the ROC curve and report AUC.
      \item Mark the operating point that minimises the cost from A2.
      \item State in two lines what AUC measures that accuracy does not.
    \end{enumerate}

\end{enumerate}

\section*{Section B (Medium) --- attempt any 1 of 2 \quad (1 $\times$ 4 = 4)}

\begin{enumerate}[label=\textbf{B\arabic*.}, leftmargin=*]

  \item \textbf{Cost-sensitive training} \QMarks{4}\\
    \emph{Dataset: A3.}
    \begin{enumerate}[label=(\alph*), leftmargin=*]
      \item Retrain with \texttt{class\_weight=\{good:1, bad:5\}} and separately by tuning the decision threshold on a validation split.
      \item Report accuracy, recall on the bad class and total cost for the baseline and both approaches.
      \item State in 4--6 lines which approach you would ship and why.
    \end{enumerate}

  \item \textbf{Group outcomes} \QMarks{4}\\
    \emph{Dataset: A3.}
    \begin{enumerate}[label=(\alph*), leftmargin=*]
      \item Split the test set by a protected-style attribute available in the data (for example \texttt{personal\_status} or age band).
      \item Report approval rate, recall and false-positive rate per group in one table.
      \item In 6--8 lines, state whether the differences you see are evidence of a problem, and what further information you would need to decide.
    \end{enumerate}

\end{enumerate}
