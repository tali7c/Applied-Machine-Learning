\begin{center}{\LARGE\textbf{Anchor Datasets}}\\[0.25em]{\large \CourseCode}\\[0.25em]\normalsize Reference for lab assignments LA1--LA10\end{center}\vspace{0.4em}\hrule\vspace{0.8em}

The ten lab assignments reuse three families of dataset. The point is that you learn the methods rather than spending every fortnight wrestling a new file format. Get each one \emph{once} into a local \texttt{data/} folder and keep it there for the semester.

\begin{warnbox}[Do this at home, before the lab]Only some of these ship inside scikit-learn. The rest \textbf{download over the internet on first use}, and the campus network may block or intercept that download. If you first run the code in the lab, you may lose the entire session. \textbf{Run the pre-fetch script below on your own connection, at home, before the lab it is needed for.} Once fetched, the data is cached on your machine and works offline afterwards.\end{warnbox}

\section*{Getting the data}

\textbf{Bundled with scikit-learn} --- nothing to do, works offline:\ \texttt{load\_digits}, \texttt{load\_breast\_cancer}, \texttt{load\_iris}, \texttt{load\_diabetes}.

\textbf{Downloads once, then cached} --- run this at home before the lab:

\begin{lstlisting}
# Pre-fetch script. Run ONCE at home, on a normal internet connection.
from sklearn.datasets import fetch_california_housing, fetch_openml

fetch_california_housing()                      # A1  ~1.4 MB
fetch_openml("credit-g", version=1, as_frame=True)   # A3  ~0.2 MB
# fetch_openml("mnist_784", version=1, as_frame=True)  # B2  ~15 MB, only if LA10 needs it
print("cached OK")
\end{lstlisting}

The cache lives in \texttt{\textasciitilde/scikit\_learn\_data/} (\texttt{C:\textbackslash Users\textbackslash<you>\textbackslash scikit\_learn\_data} on Windows).

\textbf{If the download fails on the campus network} you will see \texttt{CERTIFICATE\_VERIFY\_FAILED}. That is the campus web filter, not your code, and you cannot fix it by editing Python. Three things that do work, best first:

\begin{enumerate}
  \item Run the pre-fetch script above \textbf{at home}, on a normal connection. The cache
        then persists and everything works offline afterwards.
  \item \textbf{Download it in your browser} --- browsers accept the campus certificate even
        when Python does not --- and save the file into the cache folder above.
  \item Copy the whole \texttt{scikit\_learn\_data} folder from a classmate who already has it.
        This is allowed, and is often the fastest fix in the room.
\end{enumerate}

\begin{warnbox}[Never do this]Do not \textit{fix} the error by turning off certificate verification. It teaches you nothing, it will not be accepted in your submission, and it is a habit that causes real harm outside this course.\end{warnbox}

\textbf{Manual download} --- fetch the file yourself and put it in \texttt{data/}:

\begin{lstlisting}
# A1 California Housing  (downloads on first use, then cached)
from sklearn.datasets import fetch_california_housing
X, y = fetch_california_housing(return_X_y=True, as_frame=True)

# A3 German Credit  (downloads on first use, then cached)
from sklearn.datasets import fetch_openml
d = fetch_openml("credit-g", version=1, as_frame=True)

# B1 digits  (bundled, offline)
from sklearn.datasets import load_digits
dig = load_digits()            # dig.images 8x8, dig.data 64 features

# B3 Breast Cancer Wisconsin  (bundled, offline)
from sklearn.datasets import load_breast_cancer
bc = load_breast_cancer(as_frame=True)

# A2 Telco / C2 SMS Spam / C1 stock / B4 leaves : place the CSV in data/
import pandas as pd
df = pd.read_csv("data/WA_Fn-UseC_-Telco-Customer-Churn.csv")
\end{lstlisting}
